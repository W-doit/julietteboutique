# Juliette Boutique

Fashion-forward boutique site for [Juliette Boutique](https://www.instagram.com/julietteboutiqueshop/).

**Directions**: https://maps.app.goo.gl/cYU9vFyHzDDiwTCR6

## Development

You need Node.js (or Bun) — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd julietteboutique
bun install
bun run dev
```
